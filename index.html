Connection settings

Steam does not let web pages read its data directly, so this page fetches your games list through a public CORS proxy. If one fails, the next is tried. You can add your own; use {url} where the encoded Steam URL goes.

The key is sent through the proxy above and kept only in this browser. Get one at steamcommunity.com/dev/apikey.
